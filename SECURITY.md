# Reporting a Vulnerability

If you come across any security concern or vulnerability in EsignCenter, please report the information via email to evan74dock@gmail.com instead of opening a GitHub issue. We will promptly respond and will collaborate with you to validate the issue, and resolve it ASAP.

EsignCenter is a self-hosted fork of [DocuSeal](https://github.com/docusealco/docuseal) and does not run a bug bounty program. If the issue also affects the upstream DocuSeal project, please report it to the DocuSeal team as well (see their security policy at security@docuseal.com).
